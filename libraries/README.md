# libraries

Здесь лежат библиотеки протоколов **в процессе разработки**. Каждая публикуется отдельно: свой
репозиторий на GitHub и свой пакет на PyPI.

| Библиотека | Папка | Репозиторий | PyPI |
|---|---|---|---|
| `mtdx62-modbus-library` | `mtdx62-modbus-library/` | [GitHub](https://github.com/sergeyastakhov/mtdx62-modbus-library) | [PyPI](https://pypi.org/project/mtdx62-modbus-library/) |

Правила для библиотеки:

- имя модуля не совпадает с доменом интеграции (`mtdx62_modbus_library` против `mtdx62`), иначе
  импорт ломается, когда рядом на пути лежит `custom_components/<domain>`;
- в библиотеке нет ни одного импорта Home Assistant;
- она не открывает соединение: транспорт передаёт интеграция;
- версия и нижние границы зависимостей включают исправления, на которые опирается код.

Документация устройства — карта регистров, руководство производителя, сканы, факты — живёт в
`docs/` библиотеки, а не в рабочей области и не в интеграции.
