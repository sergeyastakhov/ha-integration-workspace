# Spec Delta

## Purpose

Датчик попутно сообщает освещённость в помещении и расстояние до обнаруженной цели. Эти
измерения нужны для сценариев «включать свет только в темноте» и для настройки зоны покрытия,
поэтому они доступны как отдельные сущности.

## ADDED Requirements

### Requirement: Датчик освещённости

Для каждого добавленного датчика интеграция SHALL создавать сущность освещённости с классом
устройства `illuminance` и единицей измерения «люкс».

Источник значения — input-регистр `0x0001`, разрешение 1, диапазон 0–255 люкс.

#### Scenario: Значение освещённости

- **WHEN** датчик отдаёт в регистре `0x0001` значение 42
- **THEN** сущность освещённости показывает 42 люкс и состояние `42`

#### Scenario: Освещённость меняется

- **WHEN** значение в регистре `0x0001` меняется с 42 на 7
- **THEN** сущность освещённости обновляется до 7 люкс без перезапуска

### Requirement: Датчик расстояния до цели

Для каждого добавленного датчика интеграция SHALL создавать сущность расстояния с классом
устройства `distance`. Значение берётся из input-регистра `0x0002` с разрешением 0.01 метра и
показывается в сантиметрах: сырое значение регистра равно числу сантиметров.

#### Scenario: Расстояние до человека

- **WHEN** датчик отдаёт в регистре `0x0002` значение 250
- **THEN** сущность расстояния показывает 250 сантиметров (2.5 метра)

#### Scenario: Человека нет

- **WHEN** датчик не обнаруживает цель и отдаёт в регистре `0x0002` значение 0
- **THEN** сущность расстояния показывает 0 сантиметров, а не `unavailable`

### Requirement: Расстояние выключено по умолчанию

Сущность расстояния SHALL быть выключена по умолчанию, потому что это вспомогательная величина:
она нужна при настройке зоны покрытия, но не в повседневных автоматизациях.

#### Scenario: Первое добавление устройства

- **WHEN** пользователь добавил новое устройство
- **THEN** сущность расстояния создана, но выключена, а сущности присутствия и освещённости
  включены

### Requirement: Освещённость и расстояние не подменяют недоступность

Если шина недоступна, обе сущности MUST переходить в `unavailable` вместе с сущностью
присутствия. Нулевое расстояние при доступном датчике MUST NOT считаться недоступностью.

#### Scenario: Шина недоступна

- **WHEN** шина перестала отвечать
- **THEN** сущности освещённости и расстояния находятся в `unavailable`
