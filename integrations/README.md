# integrations

Здесь лежат папки интеграций **в процессе разработки**. В репозиторий рабочей области они не
входят: каждая интеграция публикуется в собственный репозиторий, потому что Marketplace требует
«один репозиторий — одна интеграция».

| Домен | Папка | Репозиторий |
|---|---|---|
| `mtdx62` | `mtdx62/` | [ha-mtdx62](https://github.com/sergeyastakhov/ha-mtdx62) |

Новую интеграцию начинайте с `AGENTS.md` в корне рабочей области и со сквозных требований в
`openspec/specs/conventions/`. В своём корне `openspec/` интеграция описывает только то, что
специфично для устройства: модель, заводские параметры, что читать для проверки связи.

Создать в рабочей области папку компонента, которого ещё нет на GitHub:

```bash
mkdir -p integrations/<domain>
# ... код, openspec/, tests/, docs/ ...
python tools/publish.py list
```

Первый `publish.py` для несуществующего репозитория упадёт на клоне: репозиторий создаётся
вручную или через API, после чего скрипт его наполнит. Это сделано намеренно — скрипт не заводит
публичные репозитории без явного решения человека.
